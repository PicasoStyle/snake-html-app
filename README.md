# Snake HTML App

A modern, touch-enabled Neon Snake game built with HTML5, CSS3, and JavaScript.

## Features
- **Neon Aesthetic:** Dark background with glowing green snake and red food.
- **Controls:**
  - **Keyboard:** Use Arrow keys or WASD.
  - **Touch:** Swipe on the screen to change direction.
- **Score:** Real-time score tracking and persistent high score (via localStorage).
- **Responsive:** Scales to fit mobile and desktop screens.

## How to Play
1. Open `index.html` in any modern web browser.
2. Use keys or swipes to guide the snake.
3. Eat the red food to grow and increase your score.
4. Avoid hitting the walls or your own tail!
